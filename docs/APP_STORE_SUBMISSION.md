## ⚠️ 1. IP(지식재산권) 리스크 — 제출 전 결정 필요

이 앱은 우마무스메(Cygames / 카카오게임즈) 관련 콘텐츠를 사용합니다. 노출 정도 순:

| 요소 | 리스크 | 설명 |
|---|---|---|
| **마장 코스맵 이미지** (gametora) | 🔴 높음 | 게임 에셋에서 파생된 이미지를 그대로 번들 → 가이드라인 5.2.1(타사 지재권) 직격 |
| 레이스명·캐릭터명 | 🟡 중간 | 사실 정보지만 상표 인접 |
| 메타데이터의 "우마무스메" 상표 사용 | 🟡 중간 | 앱 이름/부제/키워드에 타사 상표 → 5.2.3 메타데이터 리젝 가능 |
| 앱 이름 "우마스케쥴" | 🟢 낮음 | 전체 상표 미사용 |

**현실**: 비공식 팬앱은 출시되기도 하지만, 권리자(Cygames는 우마무스메 IP에 적극적) 신고로 내려갈 수 있고, 심사 단계에서 리젝될 수 있습니다. 면책 문구가 도움은 되나 완전 보호는 아닙니다.

**선택지**
- **(A) 코스맵 그대로 제출** — UX 최상, 리스크 최고. 리젝/삭제 시 리스팅 손실.
- **(B) 코스맵을 자체 다이어그램으로 대체 (권장)** — 이미 fallback으로 구현된 `CourseDiagramView`는 **거리·잔디/더트·방향(사실 데이터)**을 앱이 직접 그린 것이라 복제 에셋이 아님 → IP 노출 대폭 감소. 세그먼트 색 코스맵은 못 보지만 기능적 코스 정보는 유지. (build 변경 필요 → build 10)
- **(C) 하이브리드** — App Store판은 다이어그램, 개인/TestFlight판은 코스맵.

> 권장: 공개 출시에는 **(B)**. 가장 노출 큰 복제 에셋을 빼고 기능은 유지.
> 메타데이터의 상표도 최소화하는 안을 함께 검토(아래 2-안전안).
