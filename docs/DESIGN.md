# 우마무스메 스케줄 위젯 — 비주얼 디자인 명세

작성일: 2026-05-22 · 톤: **Frost Minimal** · 플랫폼: iOS 위젯(WidgetKit, SwiftUI)

이 문서는 디자인 반복(브라우저 목업 v1~v6)에서 확정된 결정사항을 정리한 것이다. 외부 디자인 도구로 시안을 만들 때 이 명세를 그대로 기준으로 쓴다.

---

## 1. 디자인 톤 — Frost Minimal

애플 네이티브 감성. 반투명 유리(frosted) 표면, 넉넉한 여백, 단색 위주에 카테고리색은 절제해서 포인트로만. 차분하고 고급스러운 느낌.

- **위젯 표면**: 밝은 반투명 재질(시스템 머티리얼). 코너 반경 ~20pt. iOS에선 `.containerBackground(.fill.tertiary)` 기반.
- **배경(홈)**: 위젯은 사용자 배경화면 위에 올라가므로 표면은 흰색 70% 불투명 + blur 톤.
- 그림자: 아주 옅게(0 4 14 / rgba(40,50,70,.10)).

## 4. 공통 규칙

- **카테고리 헤더** = 왼쪽 점(7pt, 카테고리색) + 같은 색 헤더 텍스트. 모든 위젯 상단에 동일.
- **우측 D-day**: 챔미·LoH·**픽업 모두** 우(상)단에 큰 D-day + 그 아래 작은 라벨(날짜 또는 "오픈까지"/"시작까지").
- **기간 표시**: `start == end`이면 단일 날짜 `M.D`. 다르면 `M.D ~ M.D`. 한국 서버 미확정이면 뒤에 `(예상)`.
- **거리구분 생략**: 마일/단거리/중거리/장거리는 「코드명」 제목(MILE/LONG/CLASSIC 등)·회차에 이미 반영되므로 본문 거리줄엔 다시 쓰지 않는다. 예: `한신 잔디 1600m` (← `(마일)` 생략).
- **마장 조건 줄**: `시계(우) · 봄 · 맑음 · 양호 · 낮` 형식. 존재하는 필드만 `·`로 연결. 순서 = 방향 · 계절 · 날씨 · 마장상태 · 시간대 (코스(외/내)가 있으면 방향 다음).
- **픽업 표기 규칙**:
  - 육성마: `N★ 이름` (별점을 **이름 앞**에). 데이터가 `이름 N★`로 들어오면 표시 시 앞으로 옮긴다.
  - 서포트: `SSR 이름 <타입>` ("SSR"은 핑크 강조, `<타입>`은 근성/지능/스피드/스태미나/파워).
  - 헤더 문구: **육성 우마무스메** / **서포트 카드** (각각 bold).
- **레이스명 등급**: 챔미는 `G1` 등 등급을 레이스명 앞에 (`G1 벚꽃상`). LoH도 동일.

## 5. 위젯별 레이아웃 (총 11종)

"주요 자동전환"(L1·M1·S1·잠금) = **챔미·LoH 중 가장 임박한 것** (픽업 제외). 현재 데이터 기준 LoH(스프린터즈, D-17)가 표시됨.

### Large (systemLarge)
- **L1 · 주요(상세)** — 헤더 / 「코드명」 / 레이스명 / **큰 마장 이미지**(가능한 크게) / 트랙 2줄:
  - 1줄: `한신 잔디 1600m`
  - 2줄: `시계(우) · 봄 · 맑음 · 양호 · 낮`
  - 우상단: D-day + 날짜(예: `7.14 (예상)`).
  - 마장 이미지 없으면 코스 도식(잔디=초록/더트=갈색 타원)으로 대체.
- **L2 · 전체 일정** — 3섹션(챔미 / LoH / 픽업)을 카드 높이에 **균등 분배**, 각 섹션 본문은 **세로 중앙** 정렬, 섹션 사이 hairline.
  - 챔미·LoH 섹션: 헤더 + 「코드명」 제목(18pt) + 레이스명 + 트랙 2줄(거리줄 / 조건줄) + 우측 D-day.
  - 픽업 섹션: 헤더 + 우측 D-day / **육성 우마무스메**(13pt) + `N★ 이름` 각 줄 / (간격) / **서포트 카드**(13pt) + `SSR 이름 <타입>` 각 줄.

### Medium (systemMedium)
- **M1 · 주요(간략)** — 헤더 / 「코드명」 / 레이스명 / 기간 / 트랙 요약(`나카야마 잔디 1200m`) + 우측 D-day.
- **M2 · 챔미 + LoH** — 2행. 각 행: 헤더 + 「코드명」 + 레이스명 + 우측 D-day.
- **M3 · 픽업** — 헤더 + 우측 큰 D-day. 본문 **2열**: 좌 = 육성 우마무스메(헤더 13pt) + `N★ 이름`들 / 우 = 서포트 카드(헤더 13pt) + `SSR 이름 <타입>`들. **가운데 얇은 회색 세로 구분선**.

### Small (systemSmall)
- **S1 · 주요(개요)** — 헤더 / 「코드명」(18pt) / 레이스명 / D-day(21pt) / 트랙 요약 + 조건 줄(작게).
- **S2 · 챔미만** / **S3 · LoH만** — S1과 동일 구조, 각 카테고리 고정. 하단에 트랙 요약 + 조건 줄(`시계(우)·봄·맑음·양호·낮`, 9~10pt).
- **S4 · 픽업만 (안A 전체 표기)** — 헤더 + D-day(16pt) / 육성 우마무스메(헤더) + `N★ 이름` 2줄 / 서포트 카드(헤더) + `SSR 이름 <타입>` 2줄. 본문 10.5pt.

### 잠금화면 (Lock)
- **accessoryRectangular** — 1줄: `카테고리 「코드명」`(예: `리그 오브 히어로스 「10회차」`) / 2줄: 레이스명(픽업이면 육성마명) / 3줄: `D-17 · 오픈까지`.
- **accessoryCircular** — 카테고리 아이콘 + 큰 숫자(17) + `일`.

### 카테고리 아이콘 (SF Symbols, 잠금/원형 등에서)
- 챔미: `trophy.fill` · LoH: `flag.checkered.2.crossed` · 픽업: `sparkles`

- 라벨 문구: "리그 오브 히어로스", "육성 우마무스메", "서포트 카드"
