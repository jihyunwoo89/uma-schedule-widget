# 우마무스메 스케줄 위젯 — 비주얼 디자인 명세

작성일: 2026-05-22 · 톤: **Frost Minimal** · 플랫폼: iOS 위젯(WidgetKit, SwiftUI)

이 문서는 디자인 반복(브라우저 목업 v1~v6)에서 확정된 결정사항을 정리한 것이다. 외부 디자인 도구로 시안을 만들 때 이 명세를 그대로 기준으로 쓴다.

---

## 1. 디자인 톤 — Frost Minimal

애플 네이티브 감성. 반투명 유리(frosted) 표면, 넉넉한 여백, 단색 위주에 카테고리색은 절제해서 포인트로만. 차분하고 고급스러운 느낌.

- **위젯 표면**: 밝은 반투명 재질(시스템 머티리얼). 코너 반경 ~20pt. iOS에선 `.containerBackground(.fill.tertiary)` 기반.
- **배경(홈)**: 위젯은 사용자 배경화면 위에 올라가므로 표면은 흰색 70% 불투명 + blur 톤.
- 그림자: 아주 옅게(0 4 14 / rgba(40,50,70,.10)).

## 4. 공통 규칙

- **카테고리 헤더** = 왼쪽 점(7pt, 카테고리색) + 같은 색 헤더 텍스트. 모든 위젯 상단에 동일.
- **우측 D-day**: 챔미·LoH·**픽업 모두** 우(상)단에 큰 D-day + 그 아래 작은 라벨(날짜 또는 "오픈까지"/"시작까지").
- **기간 표시**: `start == end`이면 단일 날짜 `M.D`. 다르면 `M.D ~ M.D`. 한국 서버 미확정이면 뒤에 `(예상)`.
- **거리구분 생략**: 마일/단거리/중거리/장거리는 「코드명」 제목(MILE/LONG/CLASSIC 등)·회차에 이미 반영되므로 본문 거리줄엔 다시 쓰지 않는다. 예: `한신 잔디 1600m` (← `(마일)` 생략).
- **마장 조건 줄**: `시계(우) · 봄 · 맑음 · 양호 · 낮` 형식. 존재하는 필드만 `·`로 연결. 순서 = 방향 · 계절 · 날씨 · 마장상태 · 시간대 (코스(외/내)가 있으면 방향 다음).
- **픽업 표기 규칙**:
  - 육성마: `N★ 이름` (별점을 **이름 앞**에). 데이터가 `이름 N★`로 들어오면 표시 시 앞으로 옮긴다.
  - 서포트: `SSR 이름 <타입>` ("SSR"은 핑크 강조, `<타입>`은 근성/지능/스피드/스태미나/파워).
  - 헤더 문구: **육성 우마무스메** / **서포트 카드** (각각 bold).
- **레이스명 등급**: 챔미는 `G1` 등 등급을 레이스명 앞에 (`G1 벚꽃상`). LoH도 동일.

## 5. 위젯별 레이아웃 (총 11종)

"주요 자동전환"(L1·M1·S1·잠금) = **챔미·LoH 중 가장 임박한 것** (픽업 제외). 현재 데이터 기준 LoH(스프린터즈, D-17)가 표시됨.

### Large (systemLarge)
- **L1 · 주요(상세)** — 헤더 / 「코드명」 / 레이스명 / **큰 마장 이미지**(가능한 크게) / 트랙 2줄:
  - 1줄: `한신 잔디 1600m`
  - 2줄: `시계(우) · 봄 · 맑음 · 양호 · 낮`
  - 우상단: D-day + 날짜(예: `7.14 (예상)`).
  - 마장 이미지 없으면 코스 도식(잔디=초록/더트=갈색 타원)으로 대체.
- **L2 · 전체 일정** — 3섹션(챔미 / LoH / 픽업)을 카드 높이에 **균등 분배**, 각 섹션 본문은 **세로 중앙** 정렬, 섹션 사이 hairline.
  - 챔미·LoH 섹션: 헤더 + 「코드명」 제목(18pt) + 레이스명 + 트랙 2줄(거리줄 / 조건줄) + 우측 D-day.
  - 픽업 섹션: 헤더 + 우측 D-day / **육성 우마무스메**(13pt) + `N★ 이름` 각 줄 / (간격) / **서포트 카드**(13pt) + `SSR 이름 <타입>` 각 줄.

### Medium (systemMedium)
- **M1 · 주요(간략)** — 헤더 / 「코드명」 / 레이스명 / 기간 / 트랙 요약(`나카야마 잔디 1200m`) + 우측 D-day.
- **M2 · 챔미 + LoH** — 2행. 각 행: 헤더 + 「코드명」 + 레이스명 + 우측 D-day.
- **M3 · 픽업** — 헤더 + 우측 큰 D-day. 본문 **2열**: 좌 = 육성 우마무스메(헤더 13pt) + `N★ 이름`들 / 우 = 서포트 카드(헤더 13pt) + `SSR 이름 <타입>`들. **가운데 얇은 회색 세로 구분선**.

### Small (systemSmall)
- **S1 · 주요(개요)** — 헤더 / 「코드명」(18pt) / 레이스명 / D-day(21pt) / 트랙 요약 + 조건 줄(작게).
- **S2 · 챔미만** / **S3 · LoH만** — S1과 동일 구조, 각 카테고리 고정. 하단에 트랙 요약 + 조건 줄(`시계(우)·봄·맑음·양호·낮`, 9~10pt).
- **S4 · 픽업만 (안A 전체 표기)** — 헤더 + D-day(16pt) / 육성 우마무스메(헤더) + `N★ 이름` 2줄 / 서포트 카드(헤더) + `SSR 이름 <타입>` 2줄. 본문 10.5pt.

### 잠금화면 (Lock)
- **accessoryRectangular** — 1줄: `카테고리 「코드명」`(예: `리그 오브 히어로스 「10회차」`) / 2줄: 레이스명(픽업이면 육성마명) / 3줄: `D-17 · 오픈까지`.
- **accessoryCircular** — 카테고리 아이콘 + 큰 숫자(17) + `일`.

### 카테고리 아이콘 (SF Symbols, 잠금/원형 등에서)
- 챔미: `trophy.fill` · LoH: `flag.checkered.2.crossed` · 픽업: `sparkles`

## 8. 최종 확정 규칙 (2026-05-22) — 뱃지 / 아이콘 / 색상

브라우저 목업 최종본 기준(`large-refined-v2.html`, `medium-small-redesign.html`, `lock-widgets.html`). 이 절이 코드 구현의 기준이다.

### 8.1 카테고리 헤더 (점 + 텍스트, 같은 색)
- 챔미 `#C79200` / LoH `#2F6FD6` / 픽업 `#C23E63`. 7pt 원형 점 + 같은 색 텍스트(11pt, 700).
- 라벨: 넓은 곳=정식명("챔피언스 미팅"/"리그 오브 히어로스"/"픽업"), **좁은 곳(스몰 전체, Large L2-B 2칸)=축약("챔미"/"LoH"/"픽업")**.

### 8.2 레이스 등급 뱃지 (`GradeBadge`)
- 라운드 직사각형(반경 5), **흰 글씨 800, ~9.5pt**, 좌우 패딩 5 / 상하 2.5.
- 색: `G1`=`#3E7BE0`(파랑) · `G2`=`#E1499A`(핑크) · `G3`=`#3FA85F`(초록) · `OP`=`#F2A521`(골드).
- 표기는 로마자: `G1`→"G I", `G2`→"G II", `G3`→"G III", `OP`→"OP".
- 데이터: `EventCard.raceGrade`(신규 추가). CM=`ChampionsMeeting.raceGrade`. LoH=`raceName` 선두에서 등급 토큰 파싱(없으면 뱃지 없음). 레이스명 부제에는 등급을 다시 쓰지 않음(뱃지로 대체).

### 8.3 레어도 뱃지 (`RarityBadge`) — 픽업 전용
- 라운드 직사각형(반경 5), **갈색 글씨 `#5C3A18` 800, ~9pt**, 흰색 미세 그림자(`0 .5 0 rgba(255,255,255,.4)`).
- **대각선 3분할 그라데이션(135°)**:
  - 무지개(3★ / SSR): `#FF9DC0`(분홍) 0% → `#8ED0FF`(하늘) 50% → `#B6E673`(연두) 100%
  - 금색(2★ / SR): `#FFFFFF` 0% → `#E6B23E` 50% → `#E6B23E` 100%
  - 은색(1★ / R): `#FFFFFF` 0% → `#C2CAD4` 50% → `#C2CAD4` 100%
- 매핑: `3★`/`SSR`→무지개, `2★`/`SR`→금색, `1★`/`R`→은색.

### 8.4 서포트 특성 아이콘 + 이름 색
- 타입 텍스트(`<근성>` 등) 제거 → **이름 우측에 특성 아이콘**(에셋), ~13pt 정사각, 반경 3.
- 에셋명(asset catalog, `Image(_, bundle:.module)`): `ic_speed`/`ic_stamina`/`ic_power`/`ic_guts`/`ic_wisdom`/`ic_group`/`ic_friend`.
- 타입(한글)→에셋 매핑: 스피드→speed, 스태미나→stamina, 파워→power, 근성→guts, 지능→wisdom, 그룹→group, 친구→friend.
- **서포트 카드 이름 글씨 = 특성 색**(가독성 위해 동일 색조 약간 진하게):
  - speed `#0D84F5` · stamina `#E63E21` · power `#E59C0D` · guts `#E44179` · wisdom `#36B783` · group `#82C63C` · friend `#E6990C`.

### 8.5 픽업 표기 / 데이터 파싱
- 육성마 데이터: `"발렌타인 애스턴 마짱 3★"` 형태(이름 + `N★`). `N★` 토큰을 어디서든 찾아 추출 → 별 개수(뱃지)·나머지 텍스트(이름). 예외 `"천장시 3★ 택 1"`→ 별3 + "천장시 택 1". `N★` 없으면 뱃지 없이 이름만.
- 표시: `[N★ 뱃지] 이름` (별을 이름 앞 뱃지로). 별 개수→레어도 뱃지 색(3★ 무지개/2★ 금/1★ 은).
- 서포트: `[SSR 뱃지] 이름(특성색) [특성 아이콘]`. 서포트 0~2개(셀렉트 픽업은 0개).
- 픽업 헤더: **육성 우마무스메** / **서포트 카드**(둘 다 bold, ~12.5pt; 스몰 ~10.5pt).

### 8.6 마장(트랙) 줄 — 2줄
- 1줄 거리: `한신 잔디 1600m` = `racecourse + " " + surface.koLabel + " " + meters + "m"` (거리구분 마일/단거리 등은 생략). → `TrackCondition.distanceLine`(신규).
- 2줄 조건: `conditionChips.joined(" · ")` = `시계(우) · 봄 · 맑음 · 양호 · 낮`.

### 8.7 D-day / 기간
- 모든 위젯 D-day는 **우(상)단**: 큰 D-day + 그 아래 작은 날짜/라벨.
- 날짜: 홈화면 `M.D`(예 `7.14`), 미확정이면 `(예상)`. `start==end`면 단일 날짜. → `PeriodFormatter.startShort`/단일 처리.
- 잠금화면 R1 하단: `D-17 · 6/7`(슬래시). → `PeriodFormatter.slash`(`M/D`).
- 스몰 D-day 크기: 챔미/LoH/픽업 **전부 동일(~15pt)** + 아래 날짜(~9pt).

### 8.8 레이스명
- bold(700, 약간 진한 `#2b2f36`). 전 위젯 공통.
- Large L1: 「코드명」과 레이스명 사이 간격 띄움.

### 8.9 위젯별 레이아웃(최종)
- **L1(=L1-C)**: 헤더+우상단 D-day/날짜 / 「코드명」+(간격)레이스명(등급뱃지) / 거리줄 / 조건줄 / **큰 마장 이미지(하단, flex 채움)**.
